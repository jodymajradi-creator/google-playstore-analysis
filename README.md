# Google Play Store Analysis

## Research Question

How does the average rating of apps and the number of installs vary according to the Category, and whether the app is free or paid (Type) on the Google Play Store?

## Project Objective

Load Google Play Store apps data from Kaggle, explore its initial structure and quality in Google Colab, and then prepare it for the rest of the cleaning, analysis, and visualization stages.

A collaborative data cleaning, merging, and analysis repository for Google Play Store applications and user reviews data.

## Repository Structure

* `notebooks/GROUP-Google play analysis.ipynb` — Jupyter Notebook containing data exploration, cleaning, merging, aggregation, and analysis steps.
* `data/processed/clean_playstore_dataset.csv` — Cleaned and merged dataset ready for analysis and visualization.
* `outputs/figures/` — Directory reserved for generated plots and visual outputs.
* `.gitignore` — Specifies untracked and temporary files to exclude from version control.

## Dataset Sources

* `googleplaystore.csv`
* `googleplaystore_user_reviews.csv`
